The existing HERBORA AI frontend is already implemented and working. Your task is to upgrade the EXISTING application into a polished, visually striking, premium, production-quality herbal intelligence platform.

Do not start a new project. Do not replace the application with a landing page. First inspect the existing codebase, routes, components, styles, assets, dependencies, and functionality. Then improve the existing implementation in place.

The current problems are:

* Colours look faded, washed out, or too pale.

* The interface does not yet feel like a finished premium product.

Your goal is to make the application feel like a polished botanical AI product that could be presented confidently in a college project demonstration or product portfolio.

### Typography overhaul

Use a refined serif for major editorial headings, such as DM Serif Display or Playfair Display.

Use Inter or Manrope for interface text.

Set a consistent responsive type scale:

* Hero headline: approximately 48–64px on desktop, 36–44px on mobile.
* Page title: 36–44px on desktop, 28–34px on mobile.
* Section headings: 26–32px.
* Card titles: 20–24px.
* Body and descriptive text: 16–18px.
* Supporting content: 15–16px.
* Labels and metadata: normally 13–14px, with sufficient contrast.

Never use tiny body copy to fit more content into a card.

Body text must use comfortable line-height around 1.55–1.75. Use suitable max-widths for paragraphs. Important descriptions must be readable without zooming.

Do not make essential information pale grey. Secondary text should still have strong contrast against its background.
