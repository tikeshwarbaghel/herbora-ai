# PROJECT: HERBORA AI — Ayurvedic Herbal Intelligence Platform

Act as a senior UI/UX designer, frontend engineer, and product architect. Build a visually exceptional, production-quality, responsive web application named **HERBORA AI**, an AI-Based Ayurvedic Herbal Knowledge and Recommendation System.

This is an academic AI/ML project with the potential to become a professional herbal knowledge platform. The frontend must look like a polished health-tech and botanical research startup product, not a generic student project or a basic admin dashboard.

IMPORTANT: Build a working, interactive application, not just a static landing page or a design mockup. All primary buttons, tabs, filters, search fields, navigation links, dialogs, upload controls, and interactive cards must work.

## 1. PRODUCT PURPOSE

The application helps users:

1. Identify medicinal herbs from uploaded leaf or plant images using an AI/ML classification model.
2. Explore structured Ayurvedic herbal knowledge.
3. Search herbs and their properties using natural-language or keyword queries.
4. Discover related herbs through similarity-based recommendations.
5. Explore plant parts, reported constituents, traditional uses, and formulations.
6. Review scientific references and distinguish traditional knowledge from research evidence.
7. View available safety information, precautions, contraindications, and documented interactions.

The system is educational and research-oriented. It does not diagnose diseases, prescribe medicines, or claim that an herb cures a condition.

There is NO GPS, location tracking, blockchain, QR-code tracking, supply-chain tracking, or user tracking functionality.

## 6. PAGE TWO — AI HERB IDENTIFICATION

Route: /identify

This is the flagship feature and should receive exceptional UI attention.

Page heading:
"Identify a medicinal herb"
Subtitle:
"Upload a clear leaf or plant image to explore a possible match."

Build a large, attractive upload workspace.

Upload component requirements:

* Drag-and-drop area.
* Click-to-browse functionality.
* Support JPG, JPEG, PNG, and WEBP.
* Display accepted file types and maximum file size.
* Show a local image preview before analysis.
* Allow replacing and removing the image.
* Validate file type and size.
* Show a helpful error message for invalid files.
* Include a "Analyze Image" button.
* Include an "Analyze Another Image" action after results are shown.
* Add a loading state with a spinner and step labels such as "Preparing image", "Analyzing image", and "Preparing results".
* Disable repeated submission while processing.

Create an attractive empty state with a botanical illustration or leaf image.

Under the upload area, add an "Image tips" panel:

* Use a clear, focused leaf image.
* Prefer natural lighting.
* Avoid heavily blurred images.
* Include a single prominent leaf when possible.

RESULT UI:
When the prediction service returns a result, display:

* Predicted common name.
* Botanical name, if available.
* Uploaded image thumbnail.
* Model confidence score as a percentage only when a real model returns a valid score.
* Top alternative predictions if provided by the model.
* A clear confidence explanation.
* "View Herb Profile" button.
* "Explore Similar Herbs" button.
* Related properties, uses, plant parts, and documented safety information.
* Research references where available.

If the model is uncertain or the image appears unsupported, provide a helpful fallback rather than confidently misidentifying the plant.

Important:
Do not fabricate real AI predictions. If the backend is not connected, use a clearly labeled demo mode with sample data and a visible "Demo result — model not connected" indicator.

Prepare the frontend service interface so a future Python API can accept an image and return:

"common_name": "Example Herb",
"botanical_name": "Example botanical name",
"confidence": 0.91,
"alternatives": [],
"model_version": "optional"
}

Treat this as an example API contract, not an actual prediction.
